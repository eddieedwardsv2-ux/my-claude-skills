What Makes an Agent

You asked: “Is a bunch of skills in one project how I start my own AI agent?” Nearly. Skills are one of four parts. By the end of this page you'll be able to name all four and spot them in your own repo.

Think of a new apprentice

Picture a sharp new apprentice starting on your solar crew. They're clever, but on day one they don't know your firm. To be useful, they need four things:

Brain

The apprentice

Clever, quick to learn. In AI this is the model: Claude.

Hands

The kit in the van

Ladders, drills, a tape measure. In AI these are tools: web search, reading pages, saving files.

Know-how

The firm's method sheets

“How we fit a panel bracket, step by step.” In AI these are skills.

Notebook

The site diary

What got done yesterday, what's next. In AI this is memory: files it reads at the start.

Put those four together and let it work on its own, and you have an agent.

Chatbot vs agent

A chatbot answers your question once, then stops. An agent keeps going round a loop until the job is done:

  1. Plan the next step
  2. Use a tool
  3. Check what happened
  4. Repeat, or report back when finished

Anthropic, the company that makes Claude, puts it this way: agents are systems where the AI “dynamically direct[s] [its] own processes and tool usage.”[1] In plain English, it decides its own next step.

Skill or plugin? A skill is one method sheet: a folder with a SKILL.md file inside. A plugin is a box set of several skills you install in one go.[2]

Superpowers is a very popular plugin (about 295,000 stars on GitHub) with skills like brainstorming and writing plans.[3] It's built mainly for writing software, which is something we'll weigh up when we pick skills for your research agent.
