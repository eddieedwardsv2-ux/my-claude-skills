# Starting point: complete beginner with a working Claude Code setup

Learner is a complete beginner to AI and tech jargon, but has already set up Claude Code (cloud, from iPhone), connected a GitHub repo, and installed Matt Pocock's skills, without understanding what they do. Mission confirmed in [[MISSION.md]]: learn agents, skills and tools safely, with a research agent as the first real build. They asked "is a bunch of skills in one project how I start my own agent?", so lesson 1 teaches the four parts of an agent (model, tools, skills, memory) and the loop.

**Implications**: Teach concepts by mapping them onto their own repo and trade experience (apprentice, method sheets, site diary). Next is designing the research agent: which skills, where outputs go, and whether Superpowers or Matt's setup earn a place.
