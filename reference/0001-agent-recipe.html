The Agent Recipe

The four parts of any AI agent, and where each one lives in your repo.

Agent = four parts, in a loop

Brain

Model

The AI that reads, thinks and writes. For you: Claude.

Hands

Tools

Things it can do: search the web, read files, save to GitHub.

Know-how

Skills

Written how-to instructions for one job. Loaded only when needed.

Notebook

Memory

Files it reads at the start, so it remembers last time.

The loop

  1. Plan the next step
  2. Use a tool
  3. Check the result
  4. Repeat until the job is done, then report back

A chatbot answers once and stops. An agent keeps looping until the job is done.[1]

In your repo

Know-how
.claude/skills/: one folder per skill, each with a SKILL.md[2]
Notebook
MISSION.md, NOTES.md, learning-records/
Hands
Built into Claude Code: web search, reading pages, editing files, git
Brain
Claude, running in Claude Code

Words

  • SkillA folder holding one SKILL.md file of instructions. Claude uses it when it's relevant, or when you type /skill-name.
  • PluginA box set: several skills (and sometimes tools) bundled together to install in one go. Superpowers and Matt Pocock's skills are both plugins.
  • RepoShort for repository: a project folder stored on GitHub, with every change saved in its history.

Golden rule

Start with the simplest thing that works. Add parts only when they clearly help.[1]
