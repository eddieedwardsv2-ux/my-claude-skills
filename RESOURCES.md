# AI Agents Resources

## Knowledge

- [Article: "Building effective agents" by Anthropic](https://www.anthropic.com/engineering/building-effective-agents)
  Anthropic's own definitions of agents vs workflows and the "augmented LLM" (model + tools + retrieval + memory). Its key advice is to start simple. Use for: what an agent is, and when not to build one.
- [Docs: Claude Code, Skills](https://code.claude.com/docs/en/skills)
  Official explanation of SKILL.md, where project skills live, and how skills differ from plugins, subagents and MCP servers. Use for: anything about skills and plugins.
- [Docs: Claude Code, cloud environments](https://code.claude.com/docs/en/cloud-environments#network-access)
  How network access works in cloud sessions. Use for: why a site is blocked and how to allow it.
- [Repo: mattpocock/skills](https://github.com/mattpocock/skills)
  Source of the teach, grill-me, to-tickets and setup skills in this repo. Use for: checking what an installed Matt Pocock skill really does.
- [Repo: obra/superpowers](https://github.com/obra/superpowers)
  A very popular plugin (~295k stars, Oct 2026) of software-development skills: brainstorming, writing plans, code review, debugging. Use for: the "stay on track and double-check" workflow the learner has heard about.
- [Repo: bradautomates/claude-video](https://github.com/bradautomates/claude-video)
  The `/watch` skill (~18k stars). Turns a video into frames and a transcript for Claude. Use for: the MacBook setup lesson later.
- [Terms: Meta automated data collection](https://developers.facebook.com/docs/development/terms-and-policies/automated-data-collection/)
  Facebook bans automated collection without permission. Use for: why Marketplace scraping is off the table.
