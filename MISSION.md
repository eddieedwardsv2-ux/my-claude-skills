# Mission: AI agents, safely, for a one-person business

## Why
Go from using AI as a basic search chatbot to using **AI agents, skills and tools** that do real work, starting with research, then marketing and finding help (recruitment). That way the jobs that sank past one-person businesses (finding leads, keeping track, doing everything alone) can be shared with AI. Along the way, understand the tech and business jargon on YouTube, on X, and in Claude's own replies, so I stop getting stuck on the same rocks.

## Success looks like
- I can watch an AI video (e.g. Matt Pocock) and explain the key words in plain English
- I can say what an agent, a skill, a tool and a connector are, and when to use each
- I understand every skill installed in my repo and can use each one on purpose
- I've built a working listings tracker and dashboard (eBay, Gumtree, Copart) with Claude Code. It's a practice project, not the end goal
- I've built my own **research agent** in this repo, a project with the right skills ready to use when needed (e.g. Matt Pocock's setup, Superpowers where it helps), and used it on a real business idea from start to finish
- I can read a business or tech reply and know what the departments and roles mean (marketing, sales, ops, HR/recruitment)

## Constraints
- **Always follow the rules and T&Cs** of every platform (GitHub, Facebook, eBay, etc.). Had a GitHub account banned once from careless forking. Safety comes first
- iPhone and Claude app only until the MacBook Air M4 arrives (end of Oct 2026)
- Works full time in roofing, so learning happens in short bursts
- Lessons short, phone-friendly, plain English, one question at a time

## Out of scope (for now)
- Scraping Facebook Marketplace or anything else that breaks a site's rules
- Deep programming. Learn enough code to direct Claude, not to become a developer
- Running a full car-flipping business. Listings are just the practice project
